# Definition of Done

The closure contract for every ticket. Do not mark work as done while any item is incomplete.

- [ ] Acceptance criteria are met.
- [ ] Tests are added and passing.
- [ ] Build, lint, and typecheck are passing.
- [ ] End-to-end behavior is verified in `<ENV>` when applicable.
- [ ] Documentation and ADRs are updated when applicable.
- [ ] Contracts remain backward-compatible, or migration and approval are recorded.
- [ ] The bound issue or project item contains the final phase state and evidence.
- [ ] The PR is opened using `.github/pull_request_template.md` and linked to the ticket.
- [ ] No unresolved placeholders or secrets are in the diff.
- [ ] Persisted content uses `<REPO_LANGUAGE>`.
- [ ] Required review gates are approved.
